# 🚗 Автошкола "Taurus" (Taurus Driving School Kyiv)

Вебзастосунок для столичної автошколи. Дозволяє переглядати курси, ціни та записуватися на навчання онлайн. Підготовлено для 4-ї практичної роботи (рівень 10 балів).

## 🛠 Технології
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Backend:** PHP 8+
- **Database:** MySQL
- **CI/CD:** GitHub Actions
- **Testing:** PHPUnit

## 🚀 Інструкція із запуску (Локально)
1. Помістіть папку проєкту в директорію вашого локального сервера (наприклад, `htdocs` для XAMPP або MAMP).
2. Створіть базу даних `taurus_db` у phpMyAdmin та імпортуйте файл `database/init.sql`.
3. Перейменуйте файл `config.example.php` на `config.php` та вкажіть ваші дані підключення до БД (файл `config.php` додано в `.gitignore`).
4. Відкрийте `http://localhost/taurus-driving-school` у браузері.
